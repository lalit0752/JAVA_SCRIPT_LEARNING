## 4 pillars of OOP
- Abstraction => Hiding internal implementation and showing only essential features.
- Encapsulation =>Bundling data (variables) and methods (functions) inside a class.
- Inheritance => One class can use properties and methods of another class.
- Polymorphism => Same method behaves differently in different classes.
